# Chapter 10 — Math Concepts Practice Lab

Interactive review for Chapter 10: Libraries & Documentation, Random Numbers, The Math Library, and Computer Number Systems.

The lab includes:
- Student first/last name and class period fields
- Four lesson tabs with immediate feedback
- Retryable coding checks
- Previous/Next Lesson navigation
- 100-point grading scale
- Final grade submission to the CSP Google Form

Open `index.html` through GitHub Pages to use the lab.
